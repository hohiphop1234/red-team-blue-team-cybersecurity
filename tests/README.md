# Test Scenarios

This directory contains test scenarios and exercises for both Red Team and Blue Team.

## Test Scenarios

### Red Team Exercises
- Network reconnaissance
- Vulnerability assessment
- Penetration testing
- Social engineering (simulated)

### Blue Team Exercises
- Log analysis
- Incident response
- Threat hunting
- Security monitoring

## Usage

These scenarios are designed for:
- Educational purposes
- Controlled testing environments
- Skill development
- Team collaboration exercises

## ⚠️ Important

Only run these tests in:
- Your own lab environment
- Authorized testing environments
- Controlled virtual machines
- Isolated networks

**Never test on production systems or systems you don't own!**
